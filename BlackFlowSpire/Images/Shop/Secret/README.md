# 秘境行商原素材

此目录原图按字节复制自 `artifacts/arknights-blackflow/secret-merchant-ui`。`source-catalog.json` 记录原名称、相对路径与UID；含机械师、商店背景、园圃与确认控件、生长分层、收获卡及材质用原贴图。未重绘或修改PNG像素。

机械师原Sprite逻辑画布为1252×1252，PNG为895×1244紧裁图，按原裁切偏移恢复显示位置。园圃图已含种子及光效，只有数量确认框另叠种子图。

种子生长场景按原RectTransform层级、锚点、中心和颜色生成；原曲线保存在 `BlackFlowSpire/Animations/Shop/cultivation.json`。粒子和Shader为Godot实现，原生资源证据、重建入口与迁移范围见根目录 `SECRET-MERCHANT.md` 和 `BLACKFLOW-SECRET-MERCHANT-ASSETS.md`。
